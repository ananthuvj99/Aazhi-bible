**L151: Nothing in the start frame leaves the shot unless the creator says so. Every rug, mat, rope and prop is named in the prompt** (s23-sh06b)

Symptom: the crew's rolled sleeping mats lie on the deck in the approved frame. The prompt and the end keyframe did not name them, so the model was free to drop or move them between shots. Ranjith: "nothing should be moved away from the frame unless I tell".

Cause: the prompts listed people and big set pieces (mast, sacks, deckhouse) but not the small props on the deck. Anything not written down can vanish or move.

Rule:
1. Before writing a prompt, list every object visible in the start frame: mats and rugs, rope coils, sacks, lanterns, the door's state, bundles. The list goes into MEMORY (Place) or NOW with each object's place in the frame.
2. POSITIVE LOCKS says: "Every prop stays exactly where it lies in the start image; nothing is added, removed or moved unless this prompt says so."
3. Every end keyframe is edited with the same list. Keyframe QC checks each listed prop is still there, in the same place.
4. A prop moves or leaves only when the creator asks; the prompt then says who moves it, when and where to.
