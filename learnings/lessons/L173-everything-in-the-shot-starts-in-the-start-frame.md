Symptom: the five vallams were meant to be hidden behind the uru at the start and come into view as the camera rose; instead, at about 5 s, they popped up out of the open sea right beside the motorboats, as if they grew out of the water.
Cause: the model does not hold things it cannot see; "hidden behind the uru" in an empty-sea start frame means they do not exist until it invents them mid-shot, wherever it likes.
Rule: anything that matters later in a shot is already in the start frame: far away, small and soft in the haze if need be, but visible. Put it into the start image (edit or inpaint the previous end frame) and let the action travel toward it. Never rely on "hidden behind X, then revealed" with a still image start.
Checklist line: Is every boat, person or prop that the shot needs later already visible in the start frame (small and far is fine)? If not, edit the start image first.
