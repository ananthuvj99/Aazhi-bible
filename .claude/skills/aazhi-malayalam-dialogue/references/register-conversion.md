## 1. Verb endings and copula

The single biggest tell. Written Malayalam loves the `-കുക` / `-ആയിരിക്കുന്നു` machinery. Speech deletes it.

| Written | Spoken |
|---|---|
| ആയിരിക്കുന്നു / ആകുന്നു | ആണ് / ആ / (nothing) |
| ആയിരുന്നു | ആരുന്നു |
| ഉണ്ടായിരുന്നു | ഒണ്ടാരുന്നു |
| ഇല്ലായിരുന്നു | ഇല്ലാരുന്നു |
| ഞാൻ പോകുകയാണ് | ഞാൻ പോവാ / പോവാണ് |
| അവൻ വരുന്നുണ്ട് | അവൻ വരുന്നൊണ്ട് / വരാ |
| ചെയ്യുന്നു | ചെയ്യുവാ |
| പറയുകയാണ് | പറയാ |
| സാധിക്കുകയില്ല | പറ്റില്ല |
| കഴിയുകയില്ല | പറ്റില്ല / വയ്യ |
| ആവശ്യമാണ് | വേണം |
| ചെയ്യേണ്ടതുണ്ട് | ചെയ്യണം |
| പറഞ്ഞിരിക്കുന്നു | പറഞ്ഞിട്ടൊണ്ട് |
| ആരംഭിക്കുക | തൊടങ്ങാ |
| ഭക്ഷണം കഴിക്കുക | കഴിക്കാ / തിന്നാ |
| നൽകുക | തരാ / കൊടുക്കാ |

## 2. Contractions and elisions

Speech eats unstressed vowels. Write what the mouth does.

| Full | Spoken |
|---|---|
| എവിടെ | എവ്ടെ |
| ഇവിടെ | ഇവ്ടെ |
| അവിടെ | അവ്ടെ |
| ഉണ്ട് | ഒണ്ട് |
| എന്താണ് | എന്താ |
| എന്തുകൊണ്ട് | എന്തിനാ |
| അതുകൊണ്ട് | അതോണ്ട് |
| ഇതുകൊണ്ട് | ഇതോണ്ട് |
| ഒന്നും ഇല്ല | ഒന്നൂല്ല |
| എന്നിട്ട് | എന്ന്ട്ട് |
| അങ്ങനെ | അങ്ങന |
| ഇങ്ങനെ | ഇങ്ങന |
| വേണ്ടായിരുന്നു | വേണ്ടാരുന്നു |
| നിനക്ക് | നെനക്ക് |
| എനിക്ക് | എനക്ക് |

Do not over-apply. One or two elisions per line reads natural; four reads as mockery of the accent. **Elide where the stress falls away, not everywhere possible.**

## 3. Sanskritic → everyday vocabulary

| Written / Sanskritic | Spoken |
|---|---|
| സമുദ്രം | കടല് |
| ജലം | വെള്ളം |
| ഗൃഹം / ഭവനം | വീട് |
| വിവാഹം | കല്യാണം |
| മത്സ്യം | മീൻ |
| മത്സ്യബന്ധനം | മീൻപിടിത്തം |
| നൗക | വള്ളം / ബോട്ട് / ഉരു |
| പിതാവ് | അപ്പൻ |
| മാതാവ് | അമ്മ |
| സഹോദരൻ | ചേട്ടൻ / അനിയൻ |
| വളരെ | ഒരുപാട് / നല്ല |
| ശ്രമിക്കുക | നോക്കാ |
| ഉത്തരം പറയുക | മറുപടി പറയാ / പറയാ |
| ദുഃഖം | സങ്കടം |
| ഭയം | പേടി |
| ക്ഷമിക്കുക | ക്ഷമിക്ക് (kept — thematic word, see note) |

**Note on ക്ഷമ.** This is the film's thematic spine and stays as-is. In dialogue it is used plainly, not reverently. In English subtitles it renders as *patience*, not *forgiveness*.

## 4. Connectives and discourse particles

| Written | Spoken |
|---|---|
| എന്നാൽ | പക്ഷേ |
| അതിനാൽ | അതോണ്ട് |
| അപ്രകാരം | അങ്ങന |
| എന്നിരുന്നാലും | എന്നാലും |
| കൂടാതെ | പിന്നെ |
| ആയതിനാൽ | *(court/Ramachandran only — keep)* |

Spoken Malayalam runs on particles, not conjunctions. Salt lines with `അല്ലേ`, `പിന്നെ`, `ന്നാ`, `ഇല്ലേ`, `ട്ടോ`, `ഡാ / ടീ`. These carry the tone the punctuation cannot.

## 5. Question forms

Written Malayalam asks in full. Speech asks in fragments.

| Written | Spoken |
|---|---|
| നിങ്ങൾ എവിടെയാണ് പോകുന്നത്? | നീയെവ്ടെ പോവാ? |
| അവൻ എപ്പോൾ വരും? | അവനെപ്പഴാ വരാ? |
| എന്താണ് സംഭവിച്ചത്? | എന്താ ഒണ്ടായേ? |
| നിനക്ക് അറിയാമോ? | നെനക്കറിയോ? |
| ശരിയല്ലേ? | അല്ലേ? |

## 6. Negation

| Written | Spoken |
|---|---|
| ഇല്ല | ഇല്ല (unchanged in the south — do **not** use ഇല്ല്യ, that is Thrissur/Palakkad) |
| വേണ്ട | വേണ്ട |
| അല്ല | അല്ല / അല്ലാ |
| ഒന്നും ഇല്ല | ഒന്നൂല്ല |
| ആർക്കും അറിയില്ല | ആർക്കും അറീല്ല |

## 7. Address and pronouns

| Written | Spoken (Kollam coastal) |
|---|---|
| താങ്കൾ | നിങ്ങൾ / ചേട്ടൻ / നീ |
| നിങ്ങൾ (singular, familiar) | നീ |
| male peer, calling out | എടാ / ഡാ |
| female peer, calling out | എടീ / ടീ |
| older man | ചേട്ടാ / അണ്ണാ |
| older woman | ചേച്ചി |
| child, affectionate | മോനെ / മോളെ |
| priest | അച്ചാ / അച്ചൻ |

`അണ്ണാ` carries the Tamil-contact colour of the southern Kollam fishing belt — useful in Palk Strait and Katchatheevu scenes, sparing elsewhere.

Avoid `ഇജ്ജ്`, `ഓൻ`, `ഓള്` — those are Malabar and will read as the wrong coast.

## 8. Era drift

### 1998 permitted English loans
ok, sorry, thanks, sir, boat, engine, diesel, radio, ice, market, license, station, case, court, jail, letter, bus, hospital, school, college, exam, party, union.

### 1998 forbidden
mobile, phone (as personal object), call, message, WhatsApp, online, internet, update, network, app, digital, laptop, email, GPS, link, upload, tag, share, screenshot, project, deadline, meeting (in the corporate sense), portfolio, deal, valuation.

### 1998 texture nouns
കത്ത് (letter), എസ്‌.ടി.ഡി. ബൂത്ത്, റേഡിയോ, ടെലിഗ്രാം, കമ്പി (telegram, colloquial), പോസ്റ്റ്‌മാൻ, റേഷൻ കട, ബ്ലാക്ക് ആൻഡ് വൈറ്റ് ടി.വി.

### 2026 speech
Heavy code-mixing is correct and characterising for Jaison, the business world, and younger characters. English enters mid-sentence without translation: *"ആ deal അപ്പഴേ close ആയതാ, ഞാൻ പറഞ്ഞില്ലേ?"*

Antony does **not** speak this way. The gap between his sentence and Jaison's is the point.

## 9. Lines that pass and lines that fail

**Fails** — subtitle Malayalam:
> ഞാൻ നിന്നോട് പറഞ്ഞിരുന്നുവല്ലോ, ഈ യാത്ര അപകടകരമാണെന്ന്.

**Passes:**
> ഞാൻ പറഞ്ഞില്ലേ, ഈ പോക്ക് ശരിയാവില്ലാന്ന്.

---

**Fails** — courtroom register in a fisherman's mouth:
> അതിനാൽ എനിക്ക് ആ കത്തിനെക്കുറിച്ച് യാതൊരു അറിവുമില്ലായിരുന്നു.

**Passes:**
> ആ കത്തിനെപ്പറ്റി എനക്കൊന്നും അറീല്ലാരുന്നു.

---

**Fails** — too long, no interruption, nobody breathes:
> നീ എന്നോട് കള്ളം പറഞ്ഞു എന്ന കാര്യം എനിക്ക് വളരെ നേരത്തെ തന്നെ മനസ്സിലായിരുന്നു എന്ന് ഞാൻ നിന്നോട് പറയാൻ ആഗ്രഹിക്കുന്നു.

**Passes:**
> നീ കള്ളം പറഞ്ഞൂന്ന് എനക്കന്നേ അറിയാം.
> — അല്ല ചേട്ടാ, ഞാൻ—
> മിണ്ടണ്ട.
