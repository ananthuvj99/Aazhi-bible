# Coastal lexicon — Alappad / Kollam, Latin Catholic fishing community

**This is a living file.** Everything below is a working draft assembled from general Kerala coastal Malayalam. Where a real line, word, or correction comes in from someone who actually speaks this dialect, add it here and mark it `[verified]`. Unmarked entries are plausible, not authoritative — prefer verified entries when both exist.

---

## Sea and boat

| Malayalam | Meaning |
|---|---|
| കടല് | sea |
| ആഴി | ocean, the deep — the title word; also river-mouth in some usage |
| അഴി | bar, river mouth where backwater meets sea |
| തിര | wave |
| ചാകര | the seasonal mud-bank shoal that brings a huge catch |
| വേലിയേറ്റം / വേലിയിറക്കം | high tide / low tide |
| കാറ്റ് | wind |
| വള്ളം | boat (small, traditional) |
| ഉരു | the Beypore wooden dhow |
| പങ്കായം | oar |
| വല | net |
| കയറ് | rope |
| പായ | sail |
| കൊടിമരം | mast |
| നങ്കൂരം | anchor |
| മീൻ | fish |
| മീൻപിടിത്തം | fishing |
| കരിമീൻ / ചാള / അയല / നെത്തോലി | pearlspot / sardine / mackerel / anchovy |
| കടലമ്മ | "mother sea" — reverential, used in fear or gratitude, not casually |
| കര | shore |
| ചങ്ങാടം | raft |

**Usage note.** Sea vocabulary should appear as ordinary working speech, not as scenery. A sailor says `വല` the way an office worker says `file` — flatly. If a sea word is doing poetic work in a line, that is a directorial choice and should be flagged, not slipped in.

## Church and faith — Latin Catholic

| Malayalam | Note |
|---|---|
| ഈശോ | Jesus — used as exclamation and in prayer |
| കർത്താവേ | Lord — exclamation of shock or grief |
| മാതാവേ | Mother (Mary) — exclamation, often by women |
| പുണ്യാളൻ / വിശുദ്ധ അന്തോണീസ് | St. Anthony — the film's patron anchor |
| അച്ചൻ | priest |
| പള്ളി | church |
| കുർബാന | Mass |
| കുമ്പസാരം | confession |
| നന്മ നിറഞ്ഞ മറിയമേ | Hail Mary, opening |
| തിരുനാൾ / പെരുന്നാൾ | feast day |
| സെമിത്തേരി | cemetery |
| വേദപാഠം | catechism class |

**Naming resonance.** Antony / അന്തോണി shares his name with the church's patron. The film should let this sit as fact, not underline it. If a character remarks on it, make it once and make it dry.

## Kinship and address

| Malayalam | Meaning |
|---|---|
| അപ്പൻ | father |
| അമ്മ | mother |
| ചേട്ടൻ / ചേട്ടായി | elder brother; also any older man |
| ചേച്ചി | elder sister; also any older woman |
| അനിയൻ / അനിയത്തി | younger brother / sister |
| മോൻ / മോള് | son / daughter, also affectionate address to any young person |
| അളിയാ | brother-in-law; also close-friend address between men |
| അണ്ണാ | Tamil-contact "elder brother" — southern Kollam belt, Palk Strait scenes |
| കൊച്ച് | small child; also affectionate for a young woman in some coastal usage |

Avoid `അപ്പച്ചൻ` and `അമ്മച്ചി` — those read Syrian Christian / Kottayam, wrong community for this film.

## Oaths, exclamations, fillers

| Malayalam | Register |
|---|---|
| എടാ / ഡാ | male, familiar |
| എടീ / ടീ | female, familiar |
| അയ്യോ | dismay |
| ഹോ | exasperation or awe |
| ഛെ | disgust, self-annoyance |
| പിന്നല്ലാതെ | "obviously" — sarcastic agreement |
| ഏയ് | dismissal, "no way" |
| ന്നാ | "then" / "so" — sentence starter |
| ട്ടോ | softener, sentence-final |
| അല്ലേ | tag question |
| മ്ം | acknowledgement grunt |

Fillers do more tonal work in this film than adjectives. A scene's warmth or coldness can be set almost entirely by whether characters use them.
