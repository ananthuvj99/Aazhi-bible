# Voices — which platform voice each character uses

The one place to look up a character's voice on the Techjays film platform. Every prompt with a speaker uses the voice listed here, and every delivery names it next to the IDs to attach. The same voice is used for every look of a character (Antony at home, dressed and at his bath all use one voice).

To change a voice or add one: edit this table and the character's `card.md` (Voice section) in the same commit, `<Name>: voice: …`. Changing an existing voice needs the creator who set it (or Ananthu) to agree.
