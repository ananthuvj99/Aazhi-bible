# Reference registry — every platform ID, what it shows, when to attach it

IDs are exactly as registered on the platform (sheet name, no spaces, no underscores).
Modes: **full** = the place/person is where the action happens · **background-only** = seen through a door/window/beyond; write "(shot N only, background only) … the camera never goes there".
Mapped sheets carry printed text labels (room names, compass words). Prefer the clean sheet; attach a mapped one only if the user chooses, and warn that labels can print into the video.
